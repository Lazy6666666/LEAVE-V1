## Getting Started

The Leave Management System is a comprehensive web application designed to streamline the process of requesting, approving, and tracking employee leave. This guide will help you navigate through all the features available to you as an employee.

### System Requirements

- **Browser**: Chrome 90+, Firefox 88+, Safari 14+, Edge 90+
- **Internet Connection**: Stable broadband connection recommended
- **Screen Resolution**: Minimum 1024x768 (recommended 1920x1080)
- **JavaScript**: Must be enabled in your browser

### Accessing the System

1. Open your web browser
2. Navigate to the company's Leave Management System URL
3. Bookmark the page for easy access

## Account Setup

### First Time Login

If this is your first time accessing the system:

1. **Email Invitation**: You'll receive an email invitation with login credentials
2. **Temporary Password**: Use the provided temporary password
3. **Password Reset**: You'll be prompted to create a new password
4. **Profile Setup**: Complete your profile information

### Creating a Strong Password

Your password must meet the following requirements:

- **Minimum length**: 8 characters
- **Uppercase letters**: At least one (A-Z)
- **Lowercase letters**: At least one (a-z)
- **Numbers**: At least one (0-9)
- **Special characters**: At least one (!@#$%^&\*)

### Password Security Tips

- Use a unique password for this system
- Don't share your password with anyone
- Change your password periodically
- Use a password manager for secure storage

## Login Process

### Step-by-Step Login

1. **Navigate to Login Page**
   - Enter the system URL in your browser
   - Click on the "Login" button if redirected to homepage

2. **Enter Credentials**

   ```
   Email: your.company@email.com
   Password: your-secure-password
   ```

3. **Two-Factor Authentication (if enabled)**
   - Enter the verification code sent to your email/phone
   - Click "Verify"

4. **Access Dashboard**
   - You'll be redirected to your personal dashboard
   - View your leave balance and recent requests

### Login Issues

**Forgot Password**:

1. Click "Forgot Password?" on the login page
2. Enter your registered email address
3. Check your email for reset instructions
4. Follow the link to create a new password

**Account Locked**:

- Contact HR department for account unlocking
- Wait 15 minutes for automatic unlock (security measure)

## Requesting Leave

### Step-by-Step Leave Request

#### 1. Navigate to Leave Request

- Click "Leave Request" in the navigation menu
- Or click the "Request Leave" button on the dashboard

#### 2. Select Leave Type

Choose from available leave types:

- **Annual Leave**: Regular vacation time
- **Sick Leave**: Health-related absence
- **Personal Leave**: Personal matters
- **Maternity/Paternity**: Family-related leave
- **Bereavement**: Family emergency leave
- **Unpaid Leave**: Leave without pay

#### 3. Select Date Range

- **Start Date**: Click to select from calendar
- **End Date**: Click to select end date
- **Partial Days**: Select half-day options if needed
- **Duration**: System automatically calculates total days

#### 4. Add Reason/Comments

- **Reason for Leave**: Brief explanation (required)
- **Additional Comments**: Optional details
- **Emergency Contact**: If applicable

#### 5. Upload Supporting Documents (if required)

- **Medical Certificate**: For sick leave >3 days
- **Travel Documents**: For international travel
- **Other Documents**: As required by company policy

#### 6. Review and Submit

- **Review Details**: Check all information is correct
- **Terms Agreement**: Confirm understanding of leave policy
- **Submit Request**: Click "Submit for Approval"

### Leave Request Rules

#### Advance Notice Requirements

- **Annual Leave**: Minimum 2 weeks notice
- **Personal Leave**: Minimum 3 days notice
- **Sick Leave**: Same-day reporting acceptable
- **Emergency Leave**: Immediate reporting required

#### Leave Balance Validation

- System prevents requests exceeding available balance
- Shows warning for insufficient balance
- Manager can approve exception if warranted

#### Blackout Periods

- Certain dates may be restricted (peak periods)
- System shows blackout dates in red
- Special approval required for blackout periods

## Managing Your Requests

### Viewing Your Requests

1. **Navigate to "My Leave"**
   - Click on "My Leave" in the navigation menu
   - View all your leave requests in chronological order

2. **Filter and Sort**
   - **Status Filter**: Pending, Approved, Rejected
   - **Date Range**: Filter by specific time periods
   - **Leave Type**: Filter by leave category
   - **Sort Options**: By date, status, or type

### Request Statuses

#### 🟡 Pending

- **Meaning**: Awaiting manager approval
- **Action Required**: None, wait for approval
- **Timeline**: Usually 24-48 hours

#### 🟢 Approved

- **Meaning**: Leave request approved
- **Action Required**: None, prepare for leave
- **Timeline**: Leave is confirmed

#### 🔴 Rejected

- **Meaning**: Leave request denied
- **Action Required**: Review reason, resubmit if needed
- **Timeline**: Contact manager for clarification

#### ⚪ Cancelled

- **Meaning**: Request cancelled by you
- **Action Required**: None
- **Timeline**: Leave days restored to balance

### Modifying or Cancelling Requests

#### Before Approval

1. **Find Request**: Locate in "My Leave" section
2. **Click Edit**: Modify dates or reason
3. **Resubmit**: Send updated request for approval

#### After Approval

1. **Request Cancellation**: Click "Cancel Request"
2. **Provide Reason**: Explain cancellation reason
3. **Confirm**: Manager approval may be required
4. **Balance Update**: Leave days restored automatically

### Request History

- **Complete History**: All past and present requests
- **Export Options**: Download as PDF or CSV
- **Print**: Print summary for records
- **Archive**: View requests from previous years

## Troubleshooting

### Common Issues

#### Login Problems

**Issue**: Can't log in to the system
**Solutions**:

1. Check email and password spelling
2. Clear browser cache and cookies
3. Try a different browser
4. Reset password using "Forgot Password"
5. Contact IT support if issues persist

#### Page Loading Issues

**Issue**: Pages are loading slowly or not at all
**Solutions**:

1. Check internet connection
2. Refresh the page (F5 or Ctrl+R)
3. Clear browser cache
4. Disable browser extensions
5. Try accessing from a different network

#### Leave Request Issues

**Issue**: Can't submit leave request
**Solutions**:

1. Check leave balance is sufficient
2. Verify dates don't conflict with existing requests
3. Ensure all required fields are completed
4. Check if documents are required and uploaded
5. Contact manager for system access issues

#### Document Upload Issues

**Issue**: Can't upload documents
**Solutions**:

1. Check file size is under 10MB
2. Verify file format is supported
3. Ensure file name doesn't contain special characters
4. Try a different browser
5. Check internet connection stability

## FAQ

**Q: How far in advance should I request annual leave?**
A: Minimum 2 weeks notice is required, but 4 weeks is recommended for planning purposes.

**Q: What happens if I need to take emergency leave?**
A: Contact your manager immediately, then submit the request in the system as soon as possible.

**Q: Can I request leave that exceeds my current balance?**
A: The system will prevent this, but your manager can approve an exception if warranted.

**Q: How do I know if my request requires documents?**
A: The system will prompt you for required documents during the request process.

**Q: Can I view my team members' leave schedules?**
A: Yes, the team calendar shows approved leave for all team members (managers have extended access).

**Q: What if I forget my password?**
A: Use the "Forgot Password" link on the login page to reset your password.

**Q: Is my data secure in the system?**
A: Yes, all data is encrypted and access is controlled through role-based permissions.

**Q: Can I access the system on my mobile device?**
A: Yes, the system is fully responsive and works on mobile devices.
